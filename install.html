SETUP GUIDE

Установка за 3 шага

Установка занимает меньше минуты. Никаких сложных манипуляций.

01

Скачай файл

Перейди на страницу Скачать и сохрани .jar файл в удобную папку.

02

Установи Forge / Fabric

Убедись, что у тебя установлен загрузчик для Minecraft 1.21.4. Рекомендуем Fabric Loader.

03

Закинь в mods

Помести .jar в папку %appdata%/.minecraft/mods и запусти игру.

Требования

Системные требования

Минимальные

  • Windows 10 64-bit
  • Java 17+
  • 4 GB RAM
  • Minecraft 1.21.4
  • Fabric Loader 0.15+

Рекомендуемые

  • Windows 10/11 64-bit
  • Java 21
  • 8+ GB RAM
  • SSD для хранения файлов
  • Fabric Loader latest
Внимание

Важные заметки

!

Отключи антивирус

Некоторые антивирусы могут ложно определять мод как угрозу. Добавь папку в исключения.

!

Только официальные сборки

Скачивай клиент только с этого сайта. Сторонние источники могут содержать вредоносный код.

!

Не используй с другого аккаунта

Клиент привязан к твоему HWID. Один аккаунт = одно устройство.
